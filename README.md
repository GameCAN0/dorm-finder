## 3. รายการฟีเจอร์ที่พัฒนาครบถ้วน (F1–F6 และฟีเจอร์เสริมครบ 3 ข้อ)

### ฟีเจอร์บังคับ (F1–F6)
* **F1 — ดึงข้อมูลด้วย `fetch` และสร้างการ์ดด้วย DOM**: ดึงข้อมูลจาก `data/dorms.json` (20 หอพักจริง) พร้อมจัดการกรณีโหลดไม่สำเร็จ (`try/catch`) และสร้างการ์ดด้วย `document.createElement()`
* **F2 — กรองหลายเงื่อนไข ค้นหาชื่อ และเรียงลำดับ**: กรองตามช่วงค่าเช่า, ระยะทางจากมหาวิทยาลัย, ประเภทห้อง (แอร์/พัดลม), และ Checkbox สิ่งอำนวยความสะดวก 8 รายการ (ตรวจสอบว่าต้องมีครบทุกข้อที่เลือกด้วย `.every()`) ร่วมกับการค้นหาชื่อหอพักและเรียงลำดับ
* **F3 — ปุ่ม "เพิ่มเพื่อเปรียบเทียบ" (สูงสุด 3 แห่ง)**: บันทึกรหัสหอพักลง `localStorage` แสดงจำนวนที่เลือกบน `<nav>` ทุกหน้า (`0/3` ถึง `3/3`) และแจ้งเตือนทันทีเมื่อเลือกเกิน 3 แห่ง
* **F4 — ตารางเปรียบเทียบ `<table>` ตามหลัก Accessibility**: ใช้ `<caption>`, `<th scope="col">`, `<th scope="row">` และไฮไลต์ค่าที่ดีที่สุดของแต่ละแถว (เช่น `★ ใกล้ที่สุด`, `★ ถูกที่สุด`, `★ ค่าไฟถูกที่สุด`) ด้วยทั้งสีและข้อความกำกับ
* **F5 — เครื่องคำนวณค่าใช้จ่ายรายเดือน**: รับค่าจำนวนหน่วยไฟและจำนวนคนพัก พร้อม HTML + JS Validation คำนวณ `ค่าเช่า + (หน่วยไฟ × อัตราค่าไฟ) + ค่าน้ำ + ค่าอินเทอร์เน็ต` และแสดงยอดหารเฉลี่ยต่อคน
* **F6 — ฟอร์มรีวิวหอพักและคะแนนเฉลี่ย**: รับคะแนนความพึงพอใจ 1–5 ด้วย `radio`, ความสะอาดและความปลอดภัยด้วย `select`, ความคิดเห็นด้วย `textarea` มี Validation บันทึกลง `localStorage` และคำนวณคะแนนเฉลี่ยรายหอพักทันที

### ฟีเจอร์เสริม (ทำครบทั้ง 3 ข้อ เพื่อเกณฑ์ G3 ระดับดีเยี่ยม)
1. **ป้าย "★ คุ้มค่า" (Best Value Badge)**: คำนวณและแสดงป้ายกำกับอัตโนมัติเมื่อค่าใช้จ่ายรวมต่อเดือนของหอพักต่ำกว่าค่าเฉลี่ยของหอที่มีประเภทห้องเดียวกัน (แอร์เฉลี่ย 5,486 บาท / พัดลมเฉลี่ย 4,618 บาท)
2. **ปุ่มเปิดเส้นทางจากหอพักไปมหาวิทยาลัยใน Google Maps**: ใช้พิกัดละติจูดและลองจิจูดจริงของหอพักเชื่อมต่อไปยังมหาวิทยาลัยราชภัฏบ้านสมเด็จเจ้าพระยา
3. **ระบบรายการโปรด (Favorites)**: กดบันทึกหอพักที่สนใจเก็บไว้ใน `localStorage` พร้อมตัวกรองแสดงเฉพาะรายการโปรดในหน้า `dorms.html`

## 4. แหล่งที่มาของข้อมูลจริงและรูปภาพ (ข้อกำหนด T8)
* **ข้อมูลหอพักจริง 20 แห่ง (`data/dorms.json`)**: รวบรวมข้อมูลค่าเช่า เงินประกัน อัตราค่าน้ำ-ค่าไฟ สิ่งอำนวยความสะดวก และช่องทางติดต่อทางการของหอพักรอบมหาวิทยาลัยราชภัฏบ้านสมเด็จเจ้าพระยา (เขตธนบุรี, คลองสาน, บางกอกใหญ่, บางกอกน้อย) จากประกาศทางการบนเว็บไซต์ [Renthub Official](https://www.renthub.in.th) (ระบุลิงก์ `sourceUrl` ไว้ในทุกอ็อบเจกต์ของ `data/dorms.json`)
* **รูปภาพประกอบ**: ใช้ภาพห้องพักภายใต้สัญญาอนุญาตใช้งานฟรีเพื่อการศึกษาจาก [Unsplash License](https://unsplash.com/license) พร้อมระบุข้อความ `alt` ที่สื่อความหมายตามบริบททุกภาพ
