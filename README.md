## ✨ รายการฟีเจอร์ที่พัฒนาแล้ว

### ฟีเจอร์บังคับ (F1 - F6)
- [x] **F1 (Fetch & DOM Cards):** ดึงข้อมูลหอพักจริง 15 แห่งจาก `data/dorms.json` และแสดงผลการ์ดหอพักผ่าน Vanilla JS DOM
- [x] **F2 (Filter, Search & Sort):** กรองหอพักตามช่วงค่าเช่า, ระยะทาง, ประเภทห้อง (แอร์/พัดลม), ค้นหาด้วยชื่อ และเช็คลิสต์สิ่งอำนวยความสะดวก (ต้องตรงครบทุกข้อที่เลือก) พร้อมเรียงลำดับตามราคาและระยะทาง
- [x] **F3 (Compare Selection & Badge):** ปุ่มเพิ่มหอพักเพื่อเปรียบเทียบสูงสุด 3 แห่ง แจ้งเตือนเมื่อเกิน โหลด/บันทึกผ่าน `localStorage` และแสดงจำนวนบนแถบเมนู (Nav Badge)
- [x] **F4 (Accessible Compare Table):** หน้าเปรียบเทียบแสดงตาราง HTML `<table>` ถูกต้องตามหลัก Accessibility (`<caption>`, `<th scope>`) พร้อมไฮไลต์ค่าที่ดีที่สุดด้วยสีเขียวและข้อความป้ายกำกับ (เช่น `✓ ถูกที่สุด`, `✓ ใกล้ที่สุด`)
- [x] **F5 (Monthly Cost Calculator):** เครื่องคำนวณประมาณการค่าใช้จ่ายรายเดือน (ค่าเช่า + ค่าไฟตามหน่วยจริง + ค่าน้ำ + ค่าเน็ต) และคำนวณยอดเฉลี่ยต่อคน
- [x] **F6 (Review & Rating System):** ฟอร์มรีวิวหอพัก พร้อมระบบ Validation (HTML & JS), บันทึกด้วย `localStorage`, คำนวณคะแนนดาว (1-5) และแสดงรีวิวล่าสุด

### ฟีเจอร์เสริม (Extra Features)
- [x] **รายการโปรด (Favorites):** กดบันทึกหอพักที่สนใจไว้ใน `localStorage`
- [x] **ป้าย "คุ้มค่า":** แสดงป้ายกำกับเมื่อค่าเช่าต่ำกว่าค่าเฉลี่ยของหอพักประเภทเดียวกัน
- [x] **Google Maps Navigation:** ปุ่มเปิดเส้นทางนำทางจากหอพักไปยังมหาวิทยาลัยบน Google Maps
