# AI Reflection รายบุคคล — สมาชิกคนที่ 3 (การดึงข้อมูล fetch และตัวกรองหลายเงื่อนไข F1, F2)
**รายวิชา SC17332 · Mini Project Smart Campus · กลุ่มที่ 7 (Dorm Finder)**

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ฉันใช้ AI ช่วยมากที่สุดในส่วนของ **การเขียนฟังก์ชันกรองหอพักหลายเงื่อนไขพร้อมกัน (ค้นหาชื่อ, ช่วงค่าเช่า, ระยะทาง, ประเภทห้อง และ Checkbox สิ่งอำนวยความสะดวก)** เนื่องจากต้องการดูแนวทางการจัดโครงสร้างโค้ดตั้งต้นที่สะอาดและครอบคลุมกรณีขอบเขต (Edge Cases) ต่างๆ ก่อนนำมาปรับแต่งให้เข้ากับโครงสร้างไฟล์ `data/dorms.json` ทั้ง 20 หอพักของกลุ่มเรา

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ระหว่างการพัฒนาและทดสอบจริง พบว่า **ในส่วนของการกรองสิ่งอำนวยความสะดวกจาก Checkbox หลายตัว ตอนแรก AI เขียนโค้ดโดยใช้เมธอด `.some()` ทำให้เมื่อติ๊กเลือกทั้ง 'ลิฟต์' และ 'ฟิตเนส' ระบบกลับแสดงหอพักที่มีแค่อย่างใดอย่างหนึ่ง ซึ่งไม่ตรงโจทย์ F2 ที่ระบุว่าต้องมีครบทุกข้อที่เลือก ฉันจึงแก้ไขโค้ดจาก `.some()` เป็น `.every()` และทดสอบกับข้อมูลจริงทั้ง 20 หอพัก** ทำให้โค้ดทำงานได้ถูกต้องตามเกณฑ์ของรายวิชาทุกข้อและไม่มี Error ใน Console

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังจากได้ลงมือปรับแก้โค้ดและทำ Code Walkthrough ร่วมกับเพื่อนในกลุ่ม ตอนนี้ฉัน **สามารถเขียนคำสั่ง `fetch()` คู่กับ `async/await` จัดการ `try/catch` รวมถึงใช้เมธอดของ Array ได้แก่ `.filter()`, `.every()`, และ `.sort()` ในการจัดการข้อมูล JSON ได้ด้วยตนเอง** และพร้อมอธิบายหรือแก้ไขโค้ดสดได้ทุกส่วน
