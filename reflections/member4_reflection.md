# AI Reflection รายบุคคล — สมาชิกคนที่ 4 (ระบบ localStorage และตารางเปรียบเทียบ F3, F4)
**รายวิชา SC17332 · Mini Project Smart Campus · กลุ่มที่ 7 (Dorm Finder)**

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ฉันใช้ AI ช่วยมากที่สุดในส่วนของ **การจัดการข้อมูลหอพักที่เลือกเปรียบเทียบสูงสุด 3 แห่งใน `localStorage` และการสร้างตาราง `<table>` เปรียบเทียบแบบไดนามิก** เนื่องจากต้องการดูแนวทางการจัดโครงสร้างโค้ดตั้งต้นที่สะอาดและครอบคลุมกรณีขอบเขต (Edge Cases) ต่างๆ ก่อนนำมาปรับแต่งให้เข้ากับโครงสร้างไฟล์ `data/dorms.json` ทั้ง 20 หอพักของกลุ่มเรา

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ระหว่างการพัฒนาและทดสอบจริง พบว่า **AI สร้างตารางเปรียบเทียบโดยใช้แค่ `<tr>` และ `<td>` ธรรมดา ไม่มี `<caption>` และ `<th scope>` อีกทั้งยังไฮไลต์ค่าที่ถูกที่สุดด้วยสีพื้นหลังเพียงอย่างเดียว ซึ่งผิดเกณฑ์ T3 และ F4 ด้าน Accessibility ฉันจึงแก้ไขให้ใช้ `<th scope="col">`, `<th scope="row">` และเพิ่มป้ายข้อความกำกับ เช่น `★ ถูกที่สุด` และ `★ ใกล้ที่สุด` ลงในเซลล์ด้วย** ทำให้โค้ดทำงานได้ถูกต้องตามเกณฑ์ของรายวิชาทุกข้อและไม่มี Error ใน Console

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังจากได้ลงมือปรับแก้โค้ดและทำ Code Walkthrough ร่วมกับเพื่อนในกลุ่ม ตอนนี้ฉัน **เข้าใจวิธีอ่านและบันทึกข้อมูลลง `localStorage` ด้วย `JSON.stringify()` และ `JSON.parse()` รวมถึงการสร้างตาราง HTML ที่ถูกต้องตามหลัก Accessibility ด้วยตนเอง** และพร้อมอธิบายหรือแก้ไขโค้ดสดได้ทุกส่วน
