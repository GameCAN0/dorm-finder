# AI Reflection รายบุคคล — สมาชิกคนที่ 5 (หน้ารายละเอียดและเครื่องคำนวณค่าใช้จ่ายรายเดือน F5)
**รายวิชา SC17332 · Mini Project Smart Campus · กลุ่มที่ 7 (Dorm Finder)**

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ฉันใช้ AI ช่วยมากที่สุดในส่วนของ **การอ่านพารามิเตอร์ `?id=` จาก URL เพื่อแสดงข้อมูลหอพัก และการเขียนสูตรคำนวณค่าใช้จ่ายรายเดือนตามจำนวนหน่วยไฟและจำนวนคนพัก** เนื่องจากต้องการดูแนวทางการจัดโครงสร้างโค้ดตั้งต้นที่สะอาดและครอบคลุมกรณีขอบเขต (Edge Cases) ต่างๆ ก่อนนำมาปรับแต่งให้เข้ากับโครงสร้างไฟล์ `data/dorms.json` ทั้ง 20 หอพักของกลุ่มเรา

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ระหว่างการพัฒนาและทดสอบจริง พบว่า **AI เขียนโค้ดผูกเหตุการณ์ปุ่มคำนวณด้วย `onclick="calculateCost()"` ลงในแท็ก HTML โดยตรง ซึ่งผิดข้อกำหนดเทคนิค T6 ที่ห้ามใช้ inline event ฉันจึงลบ `onclick` ออกจาก HTML ทั้งหมด แล้วนำมาผูกด้วย `addEventListener('input', ...)` และ `'submit'` ในไฟล์ JavaScript แทน** ทำให้โค้ดทำงานได้ถูกต้องตามเกณฑ์ของรายวิชาทุกข้อและไม่มี Error ใน Console

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังจากได้ลงมือปรับแก้โค้ดและทำ Code Walkthrough ร่วมกับเพื่อนในกลุ่ม ตอนนี้ฉัน **เข้าใจการดึงพารามิเตอร์จาก URL ด้วย `URLSearchParams` การตรวจสอบความถูกต้องของข้อมูลในฟอร์ม (Form Validation) และการผูก `addEventListener` เพื่อคำนวณผลลัพธ์แบบเรียลไทม์ได้ด้วยตนเอง** และพร้อมอธิบายหรือแก้ไขโค้ดสดได้ทุกส่วน
