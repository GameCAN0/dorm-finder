# AI Reflection รายบุคคล — สมาชิกคนที่ 6 (ฟอร์มรีวิวหอพัก F6 และการตรวจสอบ Accessibility)
**รายวิชา SC17332 · Mini Project Smart Campus · กลุ่มที่ 7 (Dorm Finder)**

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ฉันใช้ AI ช่วยมากที่สุดในส่วนของ **การสร้างฟอร์มรีวิวที่มีครบทั้ง `radio`, `select`, `textarea` พร้อมระบบ Validation และการคำนวณคะแนนเฉลี่ยของแต่ละหอพัก** เนื่องจากต้องการดูแนวทางการจัดโครงสร้างโค้ดตั้งต้นที่สะอาดและครอบคลุมกรณีขอบเขต (Edge Cases) ต่างๆ ก่อนนำมาปรับแต่งให้เข้ากับโครงสร้างไฟล์ `data/dorms.json` ทั้ง 20 หอพักของกลุ่มเรา

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ระหว่างการพัฒนาและทดสอบจริง พบว่า **เมื่อนำคะแนนรีวิวจากฟอร์มมาหาค่าเฉลี่ย AI ลืมแปลงค่าที่อ่านได้จาก `input.value` (ซึ่งเป็น String) ให้เป็นตัวเลขก่อนนำเข้า `.reduce()` ทำให้การบวกคะแนนกลายเป็น String ต่อกัน (เช่น `'5' + '4'` กลายเป็น `'54'`) ฉันสังเกตเห็นค่าเฉลี่ยผิดปกติขณะทดสอบ จึงครอบด้วย `Number()` ก่อนคำนวณและใส่การดักจับกรณีที่หอพักยังไม่มีรีวิว** ทำให้โค้ดทำงานได้ถูกต้องตามเกณฑ์ของรายวิชาทุกข้อและไม่มี Error ใน Console

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังจากได้ลงมือปรับแก้โค้ดและทำ Code Walkthrough ร่วมกับเพื่อนในกลุ่ม ตอนนี้ฉัน **เข้าใจการทำ Form Validation ทั้งฝั่ง HTML และ JavaScript การผูก `<label for="...">` กับ `<input id="...">` อย่างถูกต้อง และการใช้เครื่องมือ Lighthouse ตรวจสอบ Accessibility ได้ด้วยตนเอง** และพร้อมอธิบายหรือแก้ไขโค้ดสดได้ทุกส่วน
