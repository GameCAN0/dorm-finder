# Individual AI Reflection

**ชื่อ-สกุล:** นายสมชาย สายโค้ด  
**รหัสนักศึกษา:** 663020001-1  
**กลุ่มที่ 7:** Dorm Finder  

---

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ส่วนที่ใช้ AI ช่วยมากที่สุดคือการวางโครงสร้าง **Responsive CSS Grid & Flexbox** และการจัดทำตารางเปรียบเทียบตามหลัก **Accessibility (WCAG)** เนื่องจากต้องการให้ CSS มีความสม่ำเสมอและรองรับหน้าจอทุกขนาดตั้งแต่ 360px, 768px ถึง 1280px โดยไม่มี Scroll แนวนอน การใช้ AI ช่วยสร้าง Structure เบื้องต้นทำให้ประหยัดเวลาในการทดสอบ Media Queries ได้มาก

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
มีในขั้นตอนการเขียนฟังก์ชันกรองข้อมูลสิ่งอำนวยความสะดวก (Facilities Filter) AI ได้แนะนำโค้ดที่ใช้ไลบรารีภายนอก (jQuery) และใช้การเช็คเงื่อนไขแบบ `some()` ซึ่งทำให้ถ้าติ๊กเลือก 2 ข้อ จะแสดงหอที่มีแม้อย่างใดอย่างหนึ่ง ซึ่งผิดโจทย์ข้อ F2 ที่ระบุว่า **"ต้องมีครบทุกข้อที่เลือก"**  
ฉันทราบได้จากการอ่านโค้ดและทดสอบรันบนเบราว์เซอร์จริง จึงแก้ไขด้วยการเปลี่ยนมาใช้ Vanilla JavaScript ล้วน และใช้ method `.every()` ในการตรวจสอบอาเรย์แทน

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
ฉันเข้าใจโครงสร้างการจัดการ state ใน **Vanilla JavaScript** ผ่าน **LocalStorage**, การควบคุม DOM Elements ด้วย `addEventListener()`, การดึงข้อมูลด้วย `fetch()` แบบ Async/Await พร้อม Error Handling รวมถึงการสร้าง Web Layout ที่ถูกต้องตามหลัก Semantic HTML5 และ Accessibility (Lighthouse Score >= 90) โดยไม่ต้องพึ่งพา Framework หรือ AI ในการเขียนโค้ดพื้นฐานเหล่านี้อีกต่อไป
