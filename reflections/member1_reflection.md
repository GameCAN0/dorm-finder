# AI Reflection รายบุคคล — สมาชิกคนที่ 1 (โครงสร้าง Semantic HTML5 และหน้าแรก)
**รายวิชา SC17332 · Mini Project Smart Campus · กลุ่มที่ 7 (Dorm Finder)**

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ฉันใช้ AI ช่วยมากที่สุดในส่วนของ **การจัดวางโครงสร้าง Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) และการดึงข้อมูลหอพักแนะนำมาแสดงบนหน้าแรก** เนื่องจากต้องการดูแนวทางการจัดโครงสร้างโค้ดตั้งต้นที่สะอาดและครอบคลุมกรณีขอบเขต (Edge Cases) ต่างๆ ก่อนนำมาปรับแต่งให้เข้ากับโครงสร้างไฟล์ `data/dorms.json` ทั้ง 20 หอพักของกลุ่มเรา

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ระหว่างการพัฒนาและทดสอบจริง พบว่า **AI เผลอใส่ `<h1>` สองจุดในหน้าเดียว คือตรงชื่อเว็บไซต์ใน `<header>` และหัวข้อหลักใน `<main>` ซึ่งผิดข้อกำหนด T1 ที่ระบุว่าต้องมี `<h1>` หน้าละหนึ่งตัว ฉันตรวจสอบพบตอนไล่ดูโครงสร้าง DOM จึงแก้ไขให้ชื่อเว็บใน `<header>` เป็น `<a>` และคง `<h1>` ไว้เฉพาะหัวข้อหลักของหน้าเท่านั้น** ทำให้โค้ดทำงานได้ถูกต้องตามเกณฑ์ของรายวิชาทุกข้อและไม่มี Error ใน Console

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังจากได้ลงมือปรับแก้โค้ดและทำ Code Walkthrough ร่วมกับเพื่อนในกลุ่ม ตอนนี้ฉัน **เข้าใจหลักการเขียน Semantic HTML5 ลำดับหัวข้อ `<h1>`–`<h3>` ที่ไม่ข้ามระดับ และการรับส่งค่าผ่าน URL Query Parameters (`dorms.html?q=...`) ด้วยตนเองโดยไม่ต้องพึ่ง AI** และพร้อมอธิบายหรือแก้ไขโค้ดสดได้ทุกส่วน
