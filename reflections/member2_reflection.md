# AI Reflection รายบุคคล — สมาชิกคนที่ 2 (CSS Layout, ตัวแปรสี และ Responsive)
**รายวิชา SC17332 · Mini Project Smart Campus · กลุ่มที่ 7 (Dorm Finder)**

### 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ฉันใช้ AI ช่วยมากที่สุดในส่วนของ **การออกแบบระบบ CSS Grid และ Flexbox ร่วมกับการตั้งค่า Breakpoints สำหรับหน้าจอ 360px, 768px และ 1280px** เนื่องจากต้องการดูแนวทางการจัดโครงสร้างโค้ดตั้งต้นที่สะอาดและครอบคลุมกรณีขอบเขต (Edge Cases) ต่างๆ ก่อนนำมาปรับแต่งให้เข้ากับโครงสร้างไฟล์ `data/dorms.json` ทั้ง 20 หอพักของกลุ่มเรา

### 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ระหว่างการพัฒนาและทดสอบจริง พบว่า **AI กำหนดความกว้างตายตัว (`width: 400px`) ให้กับการ์ดในบางจุด ทำให้เมื่อเปิดทดสอบที่หน้าจอความกว้าง 360px ใน Chrome DevTools เกิดแถบเลื่อนแนวนอน (Horizontal Scroll) ซึ่งผิดข้อกำหนด T5 ฉันจึงลบความกว้างตายตัวออกและเปลี่ยนมาใช้ `grid-template-columns: 1fr` ร่วมกับ `max-width: 100%`** ทำให้โค้ดทำงานได้ถูกต้องตามเกณฑ์ของรายวิชาทุกข้อและไม่มี Error ใน Console

### 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
หลังจากได้ลงมือปรับแก้โค้ดและทำ Code Walkthrough ร่วมกับเพื่อนในกลุ่ม ตอนนี้ฉัน **เข้าใจการเขียน CSS แบบ Mobile-First การใช้ CSS Custom Properties (`--color-primary`) และการแบ่งหน้าที่ระหว่าง Flexbox (จัดแนวแกนเดียว เช่น แถบเมนู) กับ CSS Grid (จัดตารางการ์ด 2 มิติ) ได้ด้วยตนเอง** และพร้อมอธิบายหรือแก้ไขโค้ดสดได้ทุกส่วน
